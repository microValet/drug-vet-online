# Друг — дополнительный домен

Тот же сайт ветеринарной клиники «Друг», опубликованный по дополнительному адресу https://drug-vet.online/.

Основной исходный проект: https://github.com/microValet/drug-vet-togliatti . Основной домен: https://drug-vet.ru/.

GitHub Pages использует ветку `main`, каталог `/docs`. Домен указан в `docs/CNAME`. Обновления основного сайта нужно также переносить в этот репозиторий; автоматической синхронизации нет. Основной адрес для поисковой индексации задан через canonical на drug-vet.ru, а OG-ссылки используют этот домен.

Сайт не собирает заявки или персональные данные. Кнопки открывают телефон, ВКонтакте и Яндекс Карты.

Дизайн использует логотип и цвет обложки публичного сообщества https://vk.ru/vetklinikatlt. Иллюстративное фото собаки — Unsplash (https://images.unsplash.com/photo-1552053831-71594a27632d). Шрифты Manrope и Oswald распространяются по SIL OFL; лицензии сохранены в `docs/assets/`.
